Este juego esta hecho para una persona. Se usa el programa random para las respuestas aleatoria.

Reglas:
- El jugador elige piedra, papel o tijera.
- La computadora elige al azar.
- Se compara quién gana la ronda.
Se necesita python 3

Que aprendi:
- Uso de condicionales (if / elif / else)
- Bucles (while)
- La librería `random`
- Entrada del usuario
